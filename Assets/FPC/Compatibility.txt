Please, install the following packages:

1) open Package Manager Window

2) install:
- Cinemachine
- Input System (if you're using the New Input System version)
- Post-processing (if you are using the Built-in render pipeline)

3) If you are using the New Input System, make sure to enable it:
- Go to Edit > Project Settings > Player > Other Settings.
- Under Configuration > Active Input Handling: choose "Both" or "Input sistem package (New)".

4) If you are using Unity 6, you may have installed Cinemachine 3.0.0 or higher.
This may have caused some errors when importing MFPC. To solve this issue:
- Open the folder "Unity 6 Compatibility".
- Click and import the package "Cinemachine 3+".

5) Optional (in the case you want to use only the Legacy input):
if you choose not to install the Input System package from the Package Manager, you need to delete some scripts.
- Search Project window > Scripts.
- Delete the "Input" folder.
- Then open the "Player" folder (Project window > Scripts > Player).
- Delete the "NewInputSystem" folder.
- All compilation errors should disappear.
